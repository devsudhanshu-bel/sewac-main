# masterCitizenSync.controller.js Documentation

## 1. File Overview

The Master Citizen Sync Controller exposes synchronization APIs for:

```text
Full Master Citizen Synchronization
Ward-specific Master Citizen Synchronization
```

It delegates synchronization logic to:

```text
masterCitizenSync.service
```

---

# 2. syncAllCitizens()

Performs a complete Master Citizen synchronization.

The operation calls:

```text
service.syncAllCitizens()
```

The controller records its own start time using:

```text
Date.now()
```

---

# 3. Global Sync Statistics

The response exposes:

```text
sourceRecords
processed
insertedOrUpdated
unmatchedWard
failed
batches
```

These statistics are supplied by the synchronization service.

---

# 4. Ward Summary

The full synchronization also reports:

```text
wardsAttempted
wardsSuccessful
wardsFailed
```

A complete list of synchronized wards is returned through:

```text
wardsSynced
```

---

# 5. Ward-Level Statistics

Each synchronized ward can contain:

```text
wardNo
wardName
wardId
wardTableName
processed
insertedOrUpdated
wardSyncStatus
mappingReceived
mappingInserted
mappingSkippedExisting
mappingSkippedInvalidPhone
mappingSyncStatus
```

---

# 6. Phone-to-Ward Mapping Statistics

The global response contains:

```text
mappingReceived
mappingValidPhones
mappingInserted
mappingSkippedExisting
mappingSkippedInvalidPhone
mappingFailed
```

This exposes the phone-to-ward mapping results generated by the service.

---

# 7. Duration

The service-provided duration is returned as:

```text
durationMs
```

The controller also calculates:

```text
totalDurationMs
```

using:

```text
Date.now() - startedAt
```

---

# 8. Full Sync Success Response

A successful full synchronization returns:

```text
HTTP 200
```

with:

```json
{
  "success": true,
  "message": "Master citizen synchronization completed successfully.",
  "data": "..."
}
```

---

# 9. Full Sync Error

Unexpected synchronization failures return:

```text
HTTP 500
```

with:

```json
{
  "success": false,
  "message": "Master citizen synchronization failed.",
  "error": "..."
}
```

---

# 10. syncOneWard()

Performs synchronization for one ward.

The ward number is read from:

```text
req.params.wardNo
```

and converted to a number.

---

# 11. Ward Number Validation

The ward number must be:

```text
an integer
greater than 0
```

Invalid input returns:

```text
HTTP 400
```

with:

```json
{
  "success": false,
  "message": "Invalid ward number.",
  "data": null
}
```

---

# 12. Ward Sync Service Call

A valid ward number is passed to:

```text
service.syncOneWard(wardNo)
```

---

# 13. Ward Identity Response

The ward-specific response includes:

```text
wardId
wardNo
wardName
wardTableName
```

---

# 14. Ward Sync Statistics

The response includes:

```text
sourceRecords
processed
insertedOrUpdated
unmatchedWard
batches
```

---

# 15. Ward Phone Mapping Statistics

The ward response also includes:

```text
mappingReceived
mappingValidPhones
mappingInserted
mappingSkippedExisting
mappingSkippedInvalidPhone
mappingFailed
```

---

# 16. Ward Sync Duration

The response includes:

```text
durationMs
totalDurationMs
```

where `totalDurationMs` is calculated by the controller.

---

# 17. Ward Sync Success Response

A successful ward synchronization returns:

```text
HTTP 200
```

with a message identifying the synchronized ward.

---

# 18. Ward Sync Error Handling

If an error message contains:

```text
not found
```

case-insensitively, the controller returns:

```text
HTTP 404
```

Otherwise it returns:

```text
HTTP 500
```

The response contains:

```json
{
  "success": false,
  "message": "Ward synchronization failed.",
  "error": "...",
  "data": null
}
```

---

# 19. Complete Flow

Full sync:

```text
Request
  ↓
service.syncAllCitizens()
  ↓
Global Statistics
  ↓
Ward Statistics
  ↓
Phone Mapping Statistics
  ↓
Duration
  ↓
HTTP 200
```

Ward sync:

```text
Request
  ↓
Validate wardNo
  ↓
service.syncOneWard()
  ↓
Ward Statistics
  ↓
Phone Mapping Statistics
  ↓
Duration
  ↓
HTTP 200
```

---

# 20. Exports

The controller exports:

```text
syncAllCitizens
syncOneWard
```

---

# 21. Summary

`masterCitizenSync.controller.js` exposes full and ward-specific Master Citizen synchronization endpoints. It delegates synchronization to the service layer, returns global and ward-level processing statistics, exposes phone-to-ward mapping metrics, measures execution duration, validates ward numbers, and distinguishes not-found synchronization failures from general server errors.
